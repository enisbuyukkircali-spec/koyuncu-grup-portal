# Koyuncu Grup Portal

Bağımsız Next.js + TypeScript ana sayfa demosu.

```sh
npm ci
npm run dev
```

Üretim kontrolü: `npm run build` ve `npm run typecheck`.

Yalnızca demo veriler kullanılır. Arama, filtre, takvim, sekmeler ve katılım seçimi tarayıcı belleğinde çalışır; sayfa yenilenince sıfırlanır. Harici API, veri tabanı ve kimlik doğrulama yoktur.

Logo ve küçük profil fotoğrafları kullanıcı referansından doğal görüntü boyutlarında alınmıştır. Bina, ofis, ürün, duyuru ve haber fotoğrafları referansa yakın üretilmiş alternatiflerdir; ürün fotoğrafları temsilidir. Tarih, hava durumu ve iletişim bilgileri örnektir.
