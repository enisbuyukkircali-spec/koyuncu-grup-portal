# Dashboard live data

No providers run during SSR/auth. The authenticated same-origin GET /api/dashboard-data loads after hydration. It accepts no user/location parameters and checks portal.home.view and password-change status. Public FX and weather data are cached independently in existing PostgreSQL; last-good payload survives cold starts. Atomic 20-second leases deduplicate across Vercel instances; process promises deduplicate concurrent requests. No auth/global write lock is used. FX TTL 60 min; weather 30 min or the longer MET Expires header. Failed refresh retries after 5 min. Client memory cache is actor-scoped, 5 min, with visible-tab refresh only. Changing a forecast slide performs no request.

- TCMB https://www.tcmb.gov.tr/kurlar/today.xml: ForexSelling / Unit, USD EUR GBP, daily indicative rates. As-of is the provider date, including holidays. No invented percentage changes.
- BIST100: intentionally unavailable (--). No free redistribution license verified; separate adapter can be connected only to an authorized provider. No subscription created.
- MET Norway Locationforecast 2.0 compact: https://api.met.no/weatherapi/locationforecast/2.0/documentation ; free including commercial use, CC BY 4.0 https://api.met.no/doc/License . Identifying User-Agent, 4 decimal coordinates, Expires and If-Modified-Since supported. Displayed daily min/max are extrema of available forecast samples; representative condition closest to noon (today closest to now). Current temperature is the nearest model forecast within 3 hours, not an observed thermometer reading. All times use Location.timezone; invalid/missing timezone falls back to Europe/Istanbul. Stale forecasts retain actual dates and never relabel old days as today.
- Coordinate fallback dataset: Open Admin Data, copyright (c) 2026 jakkrapongt, https://github.com/open-admin-data/turkey-administrative-divisions , CC BY 4.0 https://creativecommons.org/licenses/by/4.0/ . Adaptation: only province/district names and coordinates from data/all-province.json and data/all-district.json retained in lib/tr-weather-locations.json. Approximate district then province position, matched by country and normalized city/district. No runtime geocoder, GPS or third-party address disclosure. For unsupported countries/ambiguous cities, admin must supply coordinates. Existing location coordinates always take priority.

Weather themes use exact MET symbol_code values (day/night suffix stripped). clear, fair/partlycloudy, cloudy, fog, lightrain, rain, heavyrain, snow/sleet and thunder families map to nine CSS atmospheres. MET has no separate drizzle code; light rain uses the drizzle visual. Unknown codes use a neutral theme. No photos, carousel package or new dependency.

No new environment variables. Migration db/004_dashboard_cache.sql runs in the existing vercel-build migration sequence. User needs an active assigned Location; country TR/Türkiye and city/district or latitude/longitude. Providers can fail independently without affecting portal/auth rendering.
